# Materiales Meza — Demo Landing Page

Demo de sitio web / propuesta de diseño para **Materiales Meza S.A.** (Alajuela, Costa Rica), empresa familiar tica de materiales de construcción, ferretería, acabados y agregados.

## 🎯 Objetivo

Landing page moderna, dinámica y con enfoque de conversión (CTA fuerte a WhatsApp) para ofrecer al cliente en reemplazo de su sitio anterior.

## ✨ Características

- Diseño responsive (móvil, tablet, escritorio)
- Animaciones al hacer scroll, contadores animados y marquesinas
- Catálogo por categorías con enlaces directos a cotización por WhatsApp
- Botón flotante de WhatsApp con CTA de compra
- Sección de productos estrella, ventajas, proceso de compra, testimonios y sucursales
- 100% HTML/CSS/JS estático — sin dependencias ni build

## 🚀 Despliegue

Sitio estático listo para Vercel. Importar el repo en [vercel.com/new](https://vercel.com/new) o desplegar con la CLI:

```bash
vercel --prod
```

## 📁 Estructura

```
index.html   → estructura y contenido
styles.css   → sistema de diseño y animaciones
script.js    → scroll reveal, contadores, menú móvil
vercel.json  → configuración de despliegue
```
